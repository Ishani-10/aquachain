# 🌊 AquaChain - Blue Carbon Registry

## Decentralized Science Platform for Coastal Ecosystem Restoration

AquaChain is a blockchain-based DeSci (Decentralized Science) platform that implements an MRV (Monitoring, Reporting, and Verification) system for blue carbon projects. It enables transparent, immutable tracking of coastal ecosystem restoration efforts including mangrove forests, seagrass meadows, and coral reefs.

### 🚀 Features

- **Blue Carbon Project Registry**: Register and track coastal restoration projects
- **Multi-Ecosystem Support**: Mangrove, Seagrass, Coral Reef, and Salt Marsh ecosystems
- **Verifier Network**: Authorized entities for project verification and validation
- **Carbon Credit Issuance**: Transparent carbon credit minting and transfer
- **Blockchain Transparency**: Immutable record of all activities and transactions
- **Web3 Integration**: Ethereum-compatible wallet connectivity

### 🏗️ Architecture

- **Smart Contracts**: Solidity-based registry on Ethereum-compatible networks
- **Frontend**: Next.js React dashboard with Tailwind CSS
- **Blockchain**: Hardhat development environment, deployable to Polygon, Ethereum, etc.
- **IPFS Integration**: Decentralized storage for project documents and verification reports

### 📊 Supported Ecosystems

- 🌿 **Mangrove Forests**: High carbon sequestration capacity
- 🌊 **Seagrass Meadows**: Underwater carbon sinks
- 🐠 **Coral Reefs**: Marine biodiversity protectors
- 🏖️ **Salt Marshes**: Coastal wetland restoration

### 🚀 Quick Start

1. **Clone the repository**
   ```bash
   git clone https://github.com/Ishani-10/aquachain
   cd aquachain
   ```

2. **Install dependencies**
   ```bash
   yarn install
   ```

3. **Start local blockchain**
   ```bash
   yarn chain
   ```

4. **Deploy contracts**
   ```bash
   yarn deploy
   ```

5. **Start the frontend**
   ```bash
   yarn dev
   ```

Visit `http://localhost:3000` to access the AquaChain dashboard.

### 📝 Project Workflow

1. **Project Registration**: Landowners/organizations register their carbon projects
2. **Initial Verification**: Authorized verifiers review project details
3. **Monitoring & Reporting**: Ongoing MRV data collection and validation
4. **Carbon Credit Issuance**: Verified sequestration leads to credit minting
5. **Market Trading**: Credits can be traded on carbon markets

### 🛠️ Tech Stack

- **Frontend**: Next.js 13, React, Tailwind CSS, DaisyUI
- **Smart Contracts**: Solidity 0.8.19, OpenZeppelin libraries
- **Blockchain Tools**: Hardhat, Ethers.js, Viem
- **Web3 Integration**: RainbowKit, Wagmi, WalletConnect
- **Testing**: Chai/Mocha for smart contracts
